# AGENTS.md — Conway's Game of Life

## Build (C++ simulator)

Uses MSYS2 UCRT64 (`C:/msys64/ucrt64/bin/g++.exe`). Build from bash:

```
g++ -O3 -march=native -mavx2 -fopenmp -std=c++17 -o gol gol_sim.cpp -lzstd -lws2_32
```

Pre-built `gol.exe` is committed. The binary requires `libzstd.dll` at runtime.

## Run

- `gol sim <config.cfg> [threads]` — config-driven sim with stagnation detection and optional archive
- `gol bench <grid_w> <grid_h> <gens> [threads]` — benchmark (no video)
- `gol video <grid_w> <grid_h> <gens> <fps> <render_w> <render_h> [threads]` — pipe RGB24 to ffmpeg
- `gol init <config.cfg>` — write default config
- `gol archive-info <file.gol>` — print archive metadata (scans actual frames, handles truncated archives)
- `gol sparse-render <file.gol> <out_w> <out_h> [max_frames] [cluster_gap]` — cluster-based sparse RGB24 pipe
- `gol render <file.gol> <rW> <rH> <fps> [flags] [cx cy cw ch] [threads]` — full-grid archive render
  - `rgb24` = age-colored (default), `gray8` = 1 byte/pixel, `monow` = 1-bit packed
  - `binary` = any alive cell in pixel region → white pixel (max visibility, no age tracking)
  - `sparse` = cluster-based tiled rendering of active regions (for sparse large grids)
  - `sparse binary` = cluster tiled with white cells on black (best visibility)
  - Flags can be combined: `gol render run.gol 3840 2160 30 sparse binary`
- `gol serve <file.gol> [port]` — HTTP server for live HTML viewer

Config files live in `configs/`. Run via MSYS2 bash:
```
./gol sim configs/16k_convergence.cfg
```

## Python tools

All Python scripts are standalone; no package manager. Dependencies:

| Tool | Dependencies |
|------|-------------|
| `analyse_gol.py` | `numpy`, `scipy`, `zstandard` |
| `cells_manager.py` | stdlib only |
| `sparse_render.py` | `numpy`, `zstandard` |
| `gol_to_video.py` | `numpy`, `zstandard` |
| `make_viewer.py` | stdlib only |

- `analyse_gol.py <file.gol>` — offline post-analysis (connected components, lineage tracking, pattern classification)
- `cells_manager.py` — unified pattern manager: `convert`, `index`, `catalog`, `compose`, `config`, `download`, `list`
- `sparse_render.py <file.gol> <out_w> <out_h> [max_frames] [cluster_gap]` — sparse clustered renderer, pipes to ffmpeg
- `gol_to_video.py <file.gol> [--out WxH] [--fps N] [--every N] [--max-frames N] [--age]` — reads .gol archive, renders full-grid RGB24, pipes to ffmpeg; use `--dry-run` for archive info only
- `make_viewer.py <coords.bin> <grid_w> <grid_h> [output.html]` — generates self-contained HTML viewer
- `serve.html` — live streaming web viewer (requires a backend serving `/info`, `/range`, `/stream`, `/frame` endpoints)

## Patterns

- Built-in patterns in `built_in_patterns/` (`.cells` format, Golly plain-text)
- `seed = <name>` in config looks up `built_in_patterns/<name>.cells`
- `seed = <path>` or `state_file = <path>` loads `.cells` or `.gol` files from any path
- Pattern index: `built_in_patterns/patterns_index.json` (generated by `cells_manager.py index`)
- Signature catalog: `built_in_patterns/catalog_signatures.json` (generated by `cells_manager.py catalog`)

## Archive format (.gol)

Compact binary format (magic `GOL1`). Uses delta+block-sparse+zstd compression by default. See `gol_sim.cpp:27-51` for full spec. Compresses extremely well with zstd (10-50x). Processed by `analyse_gol.py`, `sparse_render.py`, and `serve.html`.

## Video pipe

```
.\gol video 3840 2160 600 60 1920 1080 8 | ffmpeg -f rawvideo -pixel_format rgb24 -video_size 1920x1080 -framerate 60 -i - -c:v libx264 -preset veryslow -crf 10 -pix_fmt yuv420p life.mp4

python gol_to_video.py longrun_4k.gol --out 1920x1080 --fps 30 | ffmpeg -f rawvideo -pixel_format rgb24 -video_size 1920x1080 -framerate 30 -i - -c:v libx264 -crf 20 -pix_fmt yuv420p output.mp4

# Binary mode (any alive cell = white pixel, max visibility)
.\gol render longrun_4k.gol 3840 2160 30 binary | ffmpeg -f rawvideo -pixel_format rgb24 -video_size 3840x2160 -framerate 30 -i - -c:v libx264 -preset veryslow -crf 18 -pix_fmt yuv420p output.mp4

# Sparse binary cluster render (best visibility for sparse grids)
.\gol render 8k_convergence.gol 3840 2160 30 sparse binary 100 | ffmpeg -f rawvideo -pixel_format rgb24 -video_size 3840x2160 -framerate 30 -i - -c:v libx264 -preset veryslow -crf 18 -pix_fmt yuv420p output.mp4
```
